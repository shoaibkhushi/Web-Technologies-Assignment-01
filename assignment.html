1. The Internet

The Internet is a global network of interconnected computer networks. It allows computers, servers, smartphones and other devices to communicate with each other.

The Internet uses standard protocols such as TCP/IP.

  • ARPANET was one of the early computer networks.
  • It was developed in 1969.
  • Today, the Internet connects devices worldwide.

2. The World Wide Web (Web)

The World Wide Web (WWW) is a collection of electronic resources available through the Internet.

The Web was invented by Tim Berners-Lee in 1989.

  1. HTML
  2. HTTP
  3. URLs
  4. Web Browsers

3. W3C — World Wide Web Consortium

W3C develops standards and recommendations for the Web.

  • HTML standards
  • CSS standards
  • Web accessibility
  • Web architecture

Visit: W3C Website

4. Web Page

A web page is a single document available on the Web. It is usually created using HTML.

Example: https://example.com/about.html

5. Website

A website is a collection of related web pages available under a common domain.

  • Home Page
  • About Page
  • Contact Page
  • Services Page
  • Blog Page

6. Home Page

The Home Page is generally the main page of a website. It provides links to other important sections.

Example: Example Website

7. Index Page

An index page is commonly the default page of a website or directory.

Common filenames are:

  • index.html
  • index.php
  • index.htm

8. Landing Page

A landing page is designed for a specific purpose. It can be opened after clicking an advertisement, email link or search result.

  1. Register for a course
  2. Buy a product
  3. Download an application
  4. Submit a form

9. Web Browser

A web browser is software used to access and display web pages.

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari

10. Web Server

A web server stores and delivers web resources to users.

  • Apache
  • Nginx
  • Microsoft IIS

Browser → HTTP/HTTPS Request → Web Server
Browser ← HTTP/HTTPS Response ← Web Server

11. Web Domain

A domain name is a human-readable name used to identify a website.

Example: www.example.com

12. URL — Uniform Resource Locator

A URL specifies the location of a resource and how it can be accessed.

Example: https://www.example.com/index.html

A URL can contain:

  • Protocol
  • Domain
  • Path

13. URI — Uniform Resource Identifier

A URI is a broader concept used to identify a resource. A URL is a type of URI.

URI: Identifies a resource.
URL: Identifies a resource and gives its location.

14. HTTP — HyperText Transfer Protocol

HTTP is a protocol used for communication between web browsers and web servers.

Browser → HTTP Request → Server

HTTP commonly uses port 80.

15. HTTPS — HyperText Transfer Protocol Secure

HTTPS is HTTP communication protected using modern cryptographic security, mainly through TLS.

  • Encryption
  • Authentication
  • Data Integrity

HTTPS commonly uses port 443.

16. SSL — Secure Sockets Layer

SSL was an earlier security protocol used to protect network communication.

SSL has been deprecated and replaced by TLS.

17. TLS — Transport Layer Security

TLS is a modern security protocol used to protect communications such as HTTPS.

It helps provide secure communication between a browser and a web server.

18. HTML — HyperText Markup Language

HTML is the standard markup language used to structure web pages.

Basic HTML structure:

<!DOCTYPE html>
<html>
<head>
    <title>Web Page</title>
</head>
<body>
    Web Page Content
</body>
</html>

HTML is used with technologies such as CSS and JavaScript.

19. IP Address

An IP address is a numeric address used to identify a device on a network.

IPv4 Example: 192.168.1.10

IPv6 Example: 2001:db8::1

20. DNS — Domain Name System

DNS translates human-readable domain names into IP addresses.

Example:
www.example.com → DNS → 93.184.216.34

21. NSlookup / nslookup

nslookup is a command-line tool used to query DNS information.

Example command: 

nslookup example.com

It can provide information about:

  • IP addresses
  • DNS servers
  • DNS records

22. Search Engines

A search engine helps users find information and web pages on the Internet.

  • Google
  • Bing
  • DuckDuckGo

Basic process:
User Query → Search Engine → Search Index → Results → User

23. ChatGPT

ChatGPT is an AI-based conversational system developed by OpenAI.

It can generate explanations, summaries, code and other content using natural-language prompts.

Visit: ChatGPT

A search engine mainly helps users find existing information, while ChatGPT generates responses based on its model and available information and tools.

24. Hyperlinks / Links

A hyperlink is a clickable reference that connects one resource to another.

HTML example: 

<a href="https://google.com">
    Visit Example
</a>

Links can connect:

  • One web page to another
  • One section to another
  • One website to another website
  • A page to a file or resource
